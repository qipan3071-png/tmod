## 灰烬之心
- 四棱水晶（菱形 + 中脊/横棱），周围一圈碎晶
- 略泛红，只有碎光点，没有光柱
- 帧表 96×110 × 4（脉冲）

## 壁炉守卫
- 机械骑士，**双腿着地，不悬浮**
- 体量按石巨人 140 的 1.3 倍：帧 184×240（约 182 宽）
- 盔内黑色，一颗红眼；胸甲一块炉心，细节压着
- 6 帧：走 4 步 + 待机/抬手
- 若采用：代码里要关 `noGravity` 悬停，改成落地走

- 白兜帽、机械身、黑眼罩（没有眼睛）
- 手里一本翻开的紫金皮书
- 帧表 112×148 × 4（上下漂 + 翻页）
